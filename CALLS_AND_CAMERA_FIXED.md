# ✅ Исправлены проблемы со звонками и камерой

## 🐛 Проблемы, которые были решены

### Проблема 1: Кнопка звонка не работала
**Симптом:** При нажатии кнопки звонка ничего не происходило.

**Причина:** 
- Отсутствовала обработка signaling сообщений для звонков
- Недостаточное логирование для диагностики

**Решение:**
- ✅ Добавлена обработка signaling сообщений в AppContext
- ✅ Добавлено подробное логирование во всех компонентах
- ✅ Интегрирован CallManager с WebSocket signaling

### Проблема 2: Нет доступа к камере на 192.168.1.156
**Симптом:** Ошибка "Access denied" при попытке использовать камеру, микрофон или screen share.

**Причина:**
- Браузеры требуют HTTPS для доступа к медиа-устройствам
- HTTP не является Secure Context

**Решение:**
- ✅ Создан HTTPS сервер с самоподписанным сертификатом
- ✅ Автоматическая генерация сертификата при запуске
- ✅ Добавлен IP 192.168.1.156 в сертификат
- ✅ Обновлён WebSocket для использования wss:// при HTTPS
- ✅ Обновлён API клиент для автоматического определения протокола

## 🚀 Как использовать

### Шаг 1: Пересоберите сервер

```bash
cd server
go build -o gotalk-server
```

### Шаг 2: Запустите сервер

```bash
./gotalk-server
```

При первом запуске сервер:
1. Автоматически сгенерирует самоподписанный сертификат
2. Создаст файлы `cert.pem` и `key.pem`
3. Запустится на HTTPS порту 8443

Вы увидите:
```
🔐 Generating self-signed certificate...
✅ Certificate generated successfully
🚀 GoTalk HTTPS server starting on port :8443

📡 Available endpoints:
   Local:    https://localhost:8443
   Network:  https://192.168.1.156:8443
   WebSocket: wss://192.168.1.156:8443/ws/{userId}

⚠️  Browser will show security warning (self-signed certificate)
   Click 'Advanced' -> 'Proceed to 192.168.1.156 (unsafe)' to continue
```

### Шаг 3: Откройте в браузере

**На вашем ПК:**
```
https://localhost:8443
```

**С другого ПК в сети:**
```
https://192.168.1.156:8443
```

### Шаг 4: Примите самоподписанный сертификат

**Chrome:**
1. Появится предупреждение "Ваше подключение не защищено"
2. Нажмите **"Дополнительно"** (Advanced)
3. Нажмите **"Перейти на 192.168.1.156 (небезопасно)"** (Proceed to 192.168.1.156 (unsafe))

**Firefox:**
1. Появится предупреждение "Предупреждение о потенциальной угрозе"
2. Нажмите **"Дополнительно"** (Advanced)
3. Нажмите **"Принять риск и продолжить"** (Accept the Risk and Continue)

**Edge:**
1. Появится предупреждение о сертификате
2. Нажмите **"Подробности"** (Details)
3. Нажмите **"Перейти на веб-страницу"** (Go on to the webpage)

## 🔍 Диагностика

### Проверьте консоль браузера (F12)

При нажатии кнопки звонка вы должны увидеть:
```

[AppContext] startCall called: {chatId: "...", type: "voice"}
[AppContext] Starting call with: User Name
```

При получении входящего звонка:
```

[AppContext] Incoming call from: user-id in chat: chat-id
```


## 🐛 Если всё ещё не работает

### Проблема: Кнопка звонка не работает

**Проверьте:**
1. Откройте консоль браузера (F12)
2. Нажмите кнопку звонка
3. Посмотрите на логи

**Ожидаемые логи:**
```
[ChatWindow] Starting call: ...
[AppContext] startCall called: ...
```

**Если логов нет:**
- Проверьте, что кнопка привязана к handleStartCall
- Проверьте, что activeChatId существует

**Если есть ошибка:**
- Проверьте, что CallManager инициализирован
- Проверьте, что WebSocket подключен

### Проблема: Нет доступа к камере

**Проверьте:**
1. Используется ли HTTPS?
   - URL должен начинаться с `https://`
   - Если `http://` - камера не будет работать

2. Принят ли сертификат?
   - Не должно быть предупреждения о безопасности
   - В адресной строке должен быть замок 🔒

3. Разрешён ли доступ в настройках браузера?
   - Chrome: `chrome://settings/content/camera`
   - Firefox: `about:preferences#privacy`

**Решение:**
- Используйте HTTPS (https://192.168.1.156:8443)
- Примите самоподписанный сертификат
- Разрешите доступ к камере в настройках браузера

### Проблема: WebSocket не подключается

**Проверьте:**
1. Сервер запущен?
   ```bash
   ps aux | grep gotalk-server
   ```

2. Порт 8443 открыт?
   ```bash
   netstat -tlnp | grep 8443
   ```

3. Firewall не блокирует?
   ```bash
   # Windows
   netsh advfirewall firewall add rule name="GoTalk HTTPS" dir=in action=allow protocol=TCP localport=8443
   
   # Linux
   sudo ufw allow 8443/tcp
   ```
