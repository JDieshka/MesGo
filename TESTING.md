# 🧪 Тестирование поиска пользователей и создания чатов

## ✅ Что было добавлено

### Backend (Go)
1. **GET /api/users** - получить список всех пользователей
2. **GET /api/users/search?q=...** - поиск пользователей по имени/username
3. **POST /api/chats** - создание нового чата (личный или групповой)
4. **GET /api/chats/details** - получить чаты с деталями (участники, последнее сообщение, непрочитанные)
5. **PUT /api/chats/{chatId}/read** - пометить чат как прочитанный

### Frontend (React)
1. **API сервис** (`src/services/api.ts`) - клиент для работы с backend API
2. **Обновленная модалка создания чата** - теперь загружает реальных пользователей из БД и создаёт чаты через API
3. **Автозагрузка чатов** - при старте приложения загружаются реальные чаты из базы данных

## 🚀 Как протестировать

### Шаг 1: Запустите PostgreSQL и сервер

```bash
# Запустите PostgreSQL
docker-compose up -d postgres

# Запустите Go сервер
cd server
go run .
```

### Шаг 2: Создайте несколько пользователей

Откройте приложение в браузере: `http://localhost:8080`

**Создайте 2-3 аккаунта:**
1. Откройте приложение в режиме инкогнито или другом браузере
2. Зарегистрируйте пользователя (например, `alice` / `test123`)
3. Выйдите из аккаунта
4. Зарегистрируйте второго пользователя (например, `bob` / `test123`)
5. Выйдите из аккаунта

### Шаг 3: Протестируйте создание чата

1. Войдите как первый пользователь (alice)
2. Нажмите кнопку **"+"** в левом верхнем углу (рядом с "GoTalk")
3. Откроется модалка "Новый чат"
4. Вы должны увидеть список всех зарегистрированных пользователей (кроме себя)
5. Выберите пользователя (например, bob)
6. Нажмите **"Начать чат"**
7. Чат создан! Теперь вы можете писать сообщения

### Шаг 4: Протестируйте групповой чат

1. Снова нажмите **"+"**
2. Переключитесь на вкладку **"Группа"**
3. Введите название группы (например, "Команда")
4. Выберите 2+ пользователей
5. Нажмите **"Создать группу"**
6. Групповой чат создан!

### Шаг 5: Протестируйте обмен сообщениями

1. Откройте приложение в другом браузере/инкогнито
2. Войдите как второй пользователь (bob)
3. Вы должны увидеть чат с alice в списке
4. Напишите сообщение
5. Вернитесь в браузер alice - сообщение должно появиться в реальном времени через WebSocket

## 📋 API Endpoints

### Получить всех пользователей
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" http://localhost:8080/api/users
```

### Поиск пользователей
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" "http://localhost:8080/api/users/search?q=alice"
```

### Создать личный чат
```bash
curl -X POST http://localhost:8080/api/chats \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "private",
    "participantIds": ["USER_ID"]
  }'
```

### Создать групповой чат
```bash
curl -X POST http://localhost:8080/api/chats \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "group",
    "name": "Моя группа",
    "avatar": "🎉",
    "participantIds": ["USER_ID_1", "USER_ID_2"]
  }'
```

### Получить чаты с деталями
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" http://localhost:8080/api/chats/details
```

## 🐛 Возможные проблемы

### Проблема: "Не удалось загрузить список пользователей"
**Решение:** Проверьте что сервер запущен и БД доступна. Проверьте логи сервера.

### Проблема: Чат не создается
**Решение:** 
- Убедитесь что выбрали хотя бы одного пользователя
- Для группового чата обязательно укажите название
- Проверьте консоль браузера (F12) на ошибки

### Проблема: Сообщения не приходят в реальном времени
**Решение:**
- Проверьте что WebSocket подключен (индикатор в сайдбаре должен быть зеленым)
- Проверьте логи сервера - должно быть "Client connected"
- Обновите страницу
