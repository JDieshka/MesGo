# ✅ Исправленные проблемы

## 🔧 Что было исправлено

### 1. Ошибка "Failed to create private chat"
**Проблема:** Неправильный `Scan` в SQL запросах (использовался `nil` вместо `time.Time`)

**Исправление:** 
- Добавлен импорт `time` в `server/chat_api.go`
- Заменён `nil` на `&lastSeen time.Time` в `rows.Scan()`
- Добавлено логирование ошибок для диагностики

### 2. Дублирование сообщений
**Проблема:** Сообщение отправлялось всем через WebSocket, включая отправителю, который уже добавил его локально

**Исправление:**
- Изменён `hub.BroadcastToChat(chatMsg.ChatID, response, "")` на `hub.BroadcastToChat(chatMsg.ChatID, response, client.ID)`
- Теперь отправитель исключается из broadcast

### 3. Очистка чата при обновлении страницы
**Проблема:** Сообщения не загружались из базы данных при выборе чата

**Исправление:**
- Добавлен новый action `SET_MESSAGES` в AppContext
- Добавлен `useEffect` для загрузки сообщений при изменении `activeChatId`
- Сообщения загружаются через `apiService.getChatMessages()`
- Чат автоматически помечается как прочитанный

## 🧪 Как протестировать исправления

### Тест 1: Создание личного чата

1. Запустите сервер:
```bash
docker-compose up -d postgres
cd server && go run .
```

2. Откройте `http://localhost:8080` и войдите как первый пользователь (например, `alice`)

3. Нажмите кнопку **"+"** в левом верхнем углу

4. Выберите пользователя (например, `bob`)

5. Нажмите **"Начать чат"**

**Ожидаемый результат:** Чат создаётся успешно, открывается окно чата

### Тест 2: Отправка сообщений без дублирования

1. В том же чате отправьте сообщение "Привет!"

2. Откройте приложение в другом браузере/инкогнито

3. Войдите как второй пользователь (`bob`)

4. Вы должны увидеть чат с `alice` и одно сообщение "Привет!" (НЕ два!)

5. Ответьте "Здравствуйте!"

6. Вернитесь в браузер `alice` - должно появиться одно сообщение "Здравствуйте!"

**Ожидаемый результат:** Сообщения не дублируются, каждое сообщение отображается один раз

### Тест 3: Сохранение сообщений при обновлении

1. В чате между `alice` и `bob` отправьте несколько сообщений

2. Обновите страницу (F5) в браузере `alice`

3. Выберите тот же чат

**Ожидаемый результат:** Все сообщения загружаются из базы данных и отображаются

### Тест 4: Групповой чат

1. Нажмите **"+"**

2. Переключитесь на вкладку **"Группа"**

3. Введите название "Команда проекта"

4. Выберите 2+ пользователей

5. Нажмите **"Создать группу"**

6. Отправьте несколько сообщений

7. Обновите страницу

**Ожидаемый результат:** 
- Группа создаётся успешно
- Сообщения не дублируются
- После обновления страницы все сообщения загружаются из БД

## 🐛 Если проблемы остались

### Ошибка "Failed to create private chat"
Проверьте логи сервера - там будет подробная ошибка. Возможные причины:
- PostgreSQL не запущен
- Неправильные credentials в DATABASE_URL
- Пользователь не существует в БД

### Дублирование сообщений
Проверьте:
- Версия кода обновлена (пересоберите: `npm run build`)
- В логах сервера нет ошибок
- WebSocket подключен (зелёный индикатор)

### Сообщения не загружаются
Проверьте:
- Откройте консоль браузера (F12) - нет ли ошибок
- Сообщения действительно сохранены в БД:
```sql
SELECT * FROM messages WHERE chat_id = '<chat-id>' ORDER BY created_at DESC;
```
