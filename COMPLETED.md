### 3. ✅ Добавлены real-time обновления

**Реализовано:**

#### WebSocket события:
- `chat-message` - новые сообщения в реальном времени
- `new-chat` - уведомления о создании новых чатов
- `user-status` - обновление статусов пользователей
- `typing` - индикатор набора текста (заготовка)

#### Автоматические обновления:
- **Сообщения** - появляются сразу у всех участников без перезагрузки
- **Чаты** - новые чаты появляются в списке у всех участников
- **Статусы** - online/offline обновляются в реальном времени
- **Счётчики** - непрочитанные сообщения обновляются автоматически
- **Сортировка** - чаты перемещаются в начало при новых сообщениях

#### Новые функции:
- `refreshChats()` - обновление списка чатов с сервера
- `refreshMessages(chatId)` - обновление сообщений для чата
- `ADD_CHAT` action - добавление нового чата в state
- Автоматический вызов `refreshChats()` при подключении WebSocket
