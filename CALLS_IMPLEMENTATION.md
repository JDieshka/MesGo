## 🔄 Поток данных

### Начало звонка
1. Пользователь нажимает кнопку "Позвонить" в ChatWindow
2. Вызывается `startCall(chatId, type)`
3. AppContext диспатчит `START_CALL` action
4. CallManager.initiateCall() создаёт WebRTC соединение
5. Отправляется `call-request` через WebSocket
6. Получатель видит входящий звонок

### Приём звонка
1. Получатель видит UI входящего звонка
2. Нажимает "Принять"
3. Вызывается `acceptCall()`
4. CallManager.acceptCall() создаёт WebRTC соединение
5. Отправляется `call-accept` через WebSocket
6. Начинается обмен SDP и ICE candidates
7. Устанавливается P2P соединение

### WebRTC signaling
1. Caller создаёт offer → отправляется через WebSocket
2. Callee получает offer → создаёт answer → отправляется через WebSocket
3. Оба обмена ICE candidates через WebSocket
4. Устанавливается P2P соединение
5. Медиа-потоки передаются напрямую между браузерами

### Управление во время звонка
- **Mute**: `toggleMute()` → отключает audio track
- **Camera**: `toggleCamera()` → отключает video track
- **Screen Share**: `toggleScreenShare()` → заменяет video track на screen track
- **End Call**: `endCall()` → закрывает WebRTC соединение, отправляет `call-end`

5. ✅ Демонстрация должна остановиться

1. **Групповые звонки** - UI готов, но WebRTC mesh network не реализован
2. **TURN сервер** - не настроен, звонки могут не работать за NAT
3. **Запись звонков** - не реализована
4. **История звонков** - не сохраняется в БД
